# Cupcakes Gourmet – PIT Engenharia de Software II
Loja virtual de cupcakes (web responsiva) – Python 3 + Flask, padrão MVC, SQLite.

    pip install flask
    python app.py            # http://127.0.0.1:5000   (loja: /admin, senha padrão admin123)
    python -m unittest tests.test_app

Variáveis de ambiente: `SECRET_KEY`, `ADMIN_PASSWORD` (troque em produção). Documentação em `docs/`.
